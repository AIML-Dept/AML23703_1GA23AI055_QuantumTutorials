 0.50     0.482     0.504     0.531     0.493    0.503    0.500    0.497    0.000
(acc = fraction decoded correctly, theory = 1 - p,
 BER b1 / b2 = error rate of the first / second message bit)

Observations:
  * Accuracy falls linearly as 1 - p for every message.
  * Only the first bit is ever corrupted; the second bit stays error-free.
  * At p = 0.5 the first bit is a coin toss, so only 1 bit of the 2 survives.
